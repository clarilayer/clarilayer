# CLI 0.3.0 instruction qualification

Observed September 17, 2026. This qualifies one native client's execution of the CLI's instruction-update request; it is not a memory-quality benchmark or proof of universal host behavior.

## Method

- Native Claude Code 2.1.238 executed the request generated by CLI 0.3.0. The observed model was `claude-opus-5[1m]`.
- Each case used a separate disposable directory and a fresh client process. Hooks, plugins from settings and automatic memory were disabled for the run. Only the selected `CLAUDE.md` target was permitted for file operations; shell and web tools were unavailable.
- A test prelude limited the task to that fixture, prohibited other memory operations and withheld any approval to resolve a conflict. The generated CLI request followed that prelude unchanged. The recorded prompt hash covers both parts.
- A local stdio proxy exposed only `get_project_stanza` and forwarded it to the live ClariLayer MCP endpoint. Each case successfully obtained mode `full`. No recall, context write, capture, consent or setup-report operation was exposed. This tests native tool execution with the live install contract through the proxy, not direct remote-MCP authentication or the full normal client tool surface.
- The generic managed contract was version 4 with payload hash `sha256:2a549743ee65b0cc81e8bd57cc30cf437fd30278f1780730616448fd3ac83a0d`.
- The legacy fixture was compared byte-for-byte with the stanza extracted from the published `clarilayer@0.2.1` package. Its SHA-256 was `d5cfafa90ba3cc2140eda2197bbf14e28e27af867338684a1939da29f18d9be2`.
- The evaluator independently checked final file bytes, unchanged surrounding content, untouched sentinel files, tool names/paths, actual full-mode calls and permission-denial records. Passing did not depend on the AI's success statement alone.

## Finding and correction

The initial five-case run passed four cases. For an existing scoped v4 block, the client correctly changed nothing but incorrectly reported `already current` based on the matching workflow payload. The request now explicitly requires `conflict/manual review` when scoped metadata is present without authenticated Connect scope. `Already current` requires equality of the entire generic range, with no instance metadata, plus the target's preamble requirements.

All six final cases below used the same corrected request. Original observations were retained; the failed initial status was not counted as a pass.

| Case | Required result | Observed file result | Check |
|---|---|---|---|
| fresh | installed | installed exact generic block | PASS |
| legacy | installed | replaced only published legacy stanza | PASS |
| edited | conflict/manual review | unchanged | PASS |
| duplicate | conflict/manual review | unchanged | PASS |
| scoped | conflict/manual review | unchanged | PASS |
| current | already current | unchanged | PASS |

Every final case called the live full-mode tool once. There were no permission denials, no file access outside the selected target in the recorded tool calls, and no writes for the four no-change cases. The scoped metadata fixture was synthetic and was not submitted as setup evidence.

The [machine-readable results](./0.3.0-native-results.json) record source/prompt hashes, client/model identity, per-case outcomes, file hashes and timing. They contain no credentials, local paths, real project identifiers or conversation history.

## Other release checks and limits

Build, typecheck and all 149 local tests passed. The suite covers command routing, the three client targets, normal/dry-run connection setup, existing/absent project instruction files, multiple detected clients, copyable prompt output, manual connection fallback and unchanged dbt contracts. Package contents and clean-install smoke are checked again from the final release artifact before npm publication.

These native cases cover Claude Code only. Codex and Cursor targets have CLI-level tests; their native installation behavior was not independently qualified in this run. The cases use synthetic local content and a bounded tool surface. They do not establish ongoing recall, use of context in answers, history-import quality or continuous capture behavior.
